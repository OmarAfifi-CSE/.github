# Getting Support

Thank you for utilizing my open-source libraries. To ensure fast issue resolution and clean project tracking, please direct your request to the right channel:

### 💬 Architecture & Usage Questions
If you need help integrating a package or have questions about best practices:
* Open a discussion in the repository's **Discussions** tab (where available).
* Post on **Stack Overflow** with the appropriate tags (`flutter`, `dart`, `windows`).

### 🐛 Bug Reports
If you discovered an actual bug, platform panic, or memory leak:
1. Check existing open and closed issues to prevent duplicates.
2. Submit a detailed **GitHub Issue** containing your environment info (`flutter doctor -v`), exact platform/OS version, and a minimal reproducible example.
